# Inbox Sorter

A browser app that helps you clean up a cluttered inbox. Paste your senders, mark the ones that matter, and the app suggests what to keep and what to filter.

## How to run
1. Download this repository.
2. Double-click `index.html`. It opens in your browser.

No install or internet connection is needed, except to load the fonts.

## How to use
1. Paste senders, one per line, as `sender, how often` (for example `news@shop.com, weekly`).
2. Click **Sort my inbox**.
3. Use the Keep and Filter buttons to change any suggestion.
4. Use the search box to find a sender, or switch to dark mode.

Your choices are saved in your browser.
